How to convert SRT to VTT

  1. Choose your .srt file, or paste the subtitle text into the box.
  2. Leave "Convert to" on Auto (an SRT file becomes WebVTT, a VTT file becomes SRT), or pick the format you want.
  3. Press Download. The file keeps the original name with the new extension.

What changes: WebVTT starts with a WEBVTT header and uses a dot before the milliseconds (00:00:01.000), while SRT numbers each cue and uses a comma (00:00:01,000). Text and timing stay the same.

FAQ

How do I convert SRT to VTT?

Choose your .srt file or paste its text, keep the target on Auto (SRT becomes WebVTT), and press Download. The tool adds the WEBVTT header and changes the comma in each timestamp to a dot. Nothing is uploaded.

How do I convert VTT to SRT?

Load the .vtt file with the target on Auto or set to SRT. The WEBVTT header is removed, cues are numbered and dots in timestamps become commas. Cue settings such as align or position cannot be stored in SRT and are dropped.

Can it convert ASS or SSA to SRT?

Yes. Load the .ass or .ssa file; each dialogue line becomes a plain text cue. Styling, colors, fonts and positioning are dropped because SRT cannot hold them.

Why do accented letters look wrong after converting?

The source file is probably not UTF-8. Choose the matching Encoding (for example windows-1251 for Russian or windows-1254 for Turkish) before converting; the output is always UTF-8.

Are my files uploaded?

No. The conversion runs in your browser with JavaScript and your file never leaves your device.

Which format should I use for HTML5 video?

The HTML5 track element expects WebVTT (.vtt). Most desktop players and many video sites accept SRT. If you need to fix timing first, use the main subtitle shifter.
