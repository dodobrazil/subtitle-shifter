How to split a subtitle file

  1. Load the subtitle file or paste it.
  2. Enter the time where the first video file ends, for example 47:12 or 2832.
  3. Press Split and download both parts.

Example: a cue at 00:50:00,000 with a split at 47:12 lands in part 2 at 00:02:48,000, because part 2 is moved back by 47 minutes 12 seconds.

Splitting is by the start time of each cue. A cue that crosses the split stays in part 1 and is cut at the split time.

FAQ

How do I split a subtitle file into two parts?

Enter the time where the first part ends (for example 47:12 or 2832 seconds) and press Split. Cues that start before that time go to part 1 and the rest go to part 2. Download both files.

Why does part 2 start at zero?

If you split a film into two video files (CD1 and CD2), the second video starts from 0:00, so its subtitles must too. Part 2 is shifted back by the split time. Untick the option to keep the original timestamps.

What happens to a cue that crosses the split time?

It stays in part 1 and its end is cut at the split time, so no line is lost or duplicated.

How do I find the split time?

Use the point where the first video file ends, usually its total length shown in a media player. A small error is fine; check the last line of part 1 and the first line of part 2.

Is my file uploaded anywhere?

No. Everything runs in your browser and the file never leaves your device.

Which formats work?

SRT, WebVTT and ASS/SSA can be loaded. Both parts are written as SRT or VTT, matching the input (ASS becomes SRT), and styling is dropped.
