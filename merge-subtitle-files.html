How to merge two subtitle files

Dual-language subtitles

  1. Load the first language as file A and the second as file B. Both must match the same video cut.
  2. Keep mode on Dual language and press Merge.
  3. Check the result and Download. Each A cue now holds its own text plus the B text that overlaps it.

Example: A has Hello at 00:00:01,000 to 00:00:03,000 and B has Hola at 00:00:01,100 to 00:00:02,900. The merged cue shows Hello on the first line and Hola on the second.

Join two parts (CD1 + CD2)

Choose Append and set the offset for B to the length of part 1 in seconds. Example: part 1 runs 47 minutes 12 seconds, so enter 2832.

Pairing uses overlap in time, so lines can pair up unevenly when the two translations split sentences differently. Skim the result before using it.

FAQ

How do I combine two subtitle files into dual-language subtitles?

Load the first language as file A and the second as file B, choose Dual language and press Merge. Each line of B is placed under the A cue it overlaps in time, so both languages show together. A keeps its timing. Download the result as SRT or VTT.

How do I join two parts of a movie subtitle (CD1 and CD2)?

Choose Append and enter the length of part 1 in seconds as the offset for file B (for example 3600 for one hour). All cues of B are moved later by that amount and added after A.

The two languages do not line up. What can I do?

Both files must come from the same cut of the video. If B is shifted by a constant amount, enter that in seconds as the offset (negative values move B earlier). If the gap grows over time, fix the frame rate or drift of B first with the other tools on this site, then merge.

What happens to cues with no partner?

By default they are kept as separate cues so no dialogue is lost. Untick the option to drop B cues that overlap no A cue.

Is my file uploaded anywhere?

No. Everything runs in your browser and the files never leave your device.

Which formats work?

SRT, WebVTT and ASS/SSA can be loaded. The result uses the format of file A (ASS becomes SRT) and styling is dropped.
