How to remove SDH from an SRT file

  1. Choose your .srt or .vtt file, or paste the text.
  2. Keep the four options ticked, or untick the ones you want to keep (for example Parentheses if they hold real dialogue).
  3. Press Remove SDH, check the result, then Download.

Example: [door slams] on its own line disappears; ANNA: Hi (laughs) becomes Hi; a cue that contained only [music] is dropped. Timing of the other cues is untouched.

FAQ

How do I remove [SDH] tags from an SRT file?

Load the .srt or .vtt file, leave the options ticked and press Download. Text in square brackets and parentheses, speaker labels like JOHN: and music-note lines are removed. Cues that end up empty are dropped and the rest are renumbered. Nothing is uploaded.

What counts as SDH or hearing-impaired text?

SDH (subtitles for the deaf and hard of hearing) adds sound descriptions such as [door slams] or (laughs), speaker names in capitals such as ANNA:, and music symbols. The tool targets these patterns only; review the result before using it.

Will it delete normal dialogue in parentheses?

It removes all text inside round brackets, so a spoken aside like (really) is also removed. Untick Parentheses if your file uses them for dialogue. Square brackets are almost always sound descriptions.

Does it change the timing?

No. Start and end times of every remaining cue stay exactly the same. If you also need to fix sync, use the main subtitle shifter.

Why was a speaker label not removed?

Only labels in capital letters followed by a colon at the start of a line are removed (ANNA:, DR. SMITH:). Mixed-case text such as Note: is kept so real dialogue is not damaged.

Which formats work?

SRT, WebVTT and ASS/SSA can be loaded. The result is SRT, or WebVTT if you load a VTT file.
